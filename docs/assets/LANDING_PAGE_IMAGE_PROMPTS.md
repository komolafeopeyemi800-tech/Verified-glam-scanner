# Tool landing page showcase images (4 per tool)

Generate **original** JPGs with ChatGPT Image, Gemini, or similar — do not copy competitor screenshots.

## Folder convention

```
images/vg/marketing/landings/{slug}/showcase-1.jpg
images/vg/marketing/landings/{slug}/showcase-2.jpg
images/vg/marketing/landings/{slug}/showcase-3.jpg
images/vg/marketing/landings/{slug}/showcase-4.jpg
```

Synced to `/assets/landings/{slug}/` on build. Used in Z-pattern showcase blocks on tool landing pages.

**Hero images** remain in `images/vg/marketing/features/`.

## Global style

- Photorealistic marketing compositions, 4:3 aspect ratio, ~1120×840 px or larger
- Plain white or soft blush (`#F6E3E3`) backgrounds
- Burgundy (`#872B3F`) UI accents only — no orange, no competitor branding
- No logos, watermarks, or readable app text
- Mix skin tones and genders across the full set

## Block mapping (Z-pattern)

| File | Typical layout on page | Visual style |
|------|------------------------|--------------|
| showcase-1.jpg | Image left | Hero feature / main tool capability |
| showcase-2.jpg | Image right | Detail / breakdown / secondary UI |
| showcase-3.jpg | Image left | Highlights / comparison / progress |
| showcase-4.jpg | Image right | Tips / action / share / outcome |
